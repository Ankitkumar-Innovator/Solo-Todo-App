✅ Solo Task Manager (To-Do App)

A simple and minimal To-Do List Web App built using vanilla JavaScript.
Designed to manage daily tasks efficiently with persistent storage.

🚀 Why I Built This

This project was built to strengthen fundamentals of:

* DOM manipulationEvent handling
* Local storage
* UI state management

Instead of using frameworks, the focus was on core JavaScript concepts.

🛠 Tech Stack
* HTML5
* CSS3
* JavaScript (Vanilla)
* Local Storage API

✨ Features
* Add new tasks
* Mark tasks as completed
* Delete tasks
* Persistent data using localStorage
* Clean and minimal UI
* Instant UI updates

🧠 Key Concepts Learned
1️⃣ DOM Manipulation
Dynamically creating elements
Updating UI based on state

2️⃣ Event Handling
Click events
Form handling
Event delegation

3️⃣ Local Storage
Storing tasks persistently
Retrieving data on reload
Syncing UI with stored data

4️⃣ State Management (Basic)
Handling task list as a data structure
Updating UI on every state change
